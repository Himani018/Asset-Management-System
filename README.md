# Asset Management System

A simple system to track, manage, and maintain organizational assets.

## Features
- Track hardware, software, and infrastructure assets
- Manage inventory and allocation
- Role-based access 
- PDF generation

## Tech Stack
- Frontend: HTML, CSS, JS
- Backend: PHP
- Database: MySQL
- Library: chart.js
